# Manuscript Result Figure Generation

This document describes how to regenerate the result figures of the manuscript.
Figures 1 and 2 are static manuscript assets and do not have public generation
scripts in this repository. The figure files `figure3` … `figure9` each have one dedicated
script. The figure files and scripts keep the numbers under which they were first produced; the
table below maps them to the figure numbers of the manuscript and its Supplementary Material.

The generation scripts preserve the committed data values, colors, markers,
line styles, legend labels, and font sizes. They use Times New Roman when it is
available; on systems without Times New Roman, Matplotlib falls back to
Liberation Serif, Nimbus Roman, or DejaVu Serif.

## Commands

Run these from the repository root:

```bash
export MPLCONFIGDIR=/tmp/mpl
python scripts/generate_paper_figure3_base_load_comparison.py --install-paper      # Figure 3
python scripts/generate_paper_figure4_sampling_sensitivity.py --install-paper      # Figure 4
python scripts/generate_paper_figure7_impairment_sweeps.py --install-paper         # Figure 5
python scripts/generate_paper_figure8_heterogeneous_response.py --install-paper    # Figure 6
python scripts/generate_paper_figure9_codebook_separation.py --install-paper       # Figure 7
python scripts/generate_paper_figure5_posterior_diagnostic.py --install-paper      # Supplementary Fig. S1
python scripts/generate_paper_figure6_ablation_summary.py --install-paper          # Figure 8
```

Each script writes first to a temporary output directory and copies the generated
PDF into `paper/` only when `--install-paper` is passed. Use `--output-dir` to
choose a different output directory and `--png` to also write a PNG preview.

The script implementation is shared in `scripts/manuscript_figure_generation.py`

into one script per figure.

## Figure 8 Ablation Data

Figure 8 (file `figure6_ablation_summary.pdf`) uses `case_study/scalability_analysis/accuracy/figure6_ablation_simulated.csv`,
tabulated from the committed Section VI-C ablation reproduction run
`case_study/scalability_analysis/accuracy/ablation_run_20260909_112655_937821/`
(12 variant algorithms × EV ∈ {100, 300, 500} × 20 repeats on the canonical
base-load scenario seeds) together with the two-prefix variant run
`case_study/scalability_analysis/accuracy/ablation_two_prefix_run_20260908_170955_253026/`
(`two_prefix_greedy`, `two_prefix_hungarian`; same seeds). The pipeline is:

```bash
# 1. (hours) re-simulate the 12 ablation variants on the canonical scenario seeds
python scripts/reproduce_all.py --mode ablation
# 1b. (≈ 1 h) re-simulate the two-prefix variant on the same seeds
python scripts/reproduce_all.py --mode ablation --algorithms two_prefix_greedy,two_prefix_hungarian

# 2. (seconds) tabulate the plotting CSV from the committed ablation summary
python scripts/build_figure6_data.py

# 3. (seconds) render and install the figure
python scripts/generate_paper_figure6_ablation_summary.py --install-paper
```

`build_figure6_data.py` enforces three integrity gates before writing: every cell
must aggregate exactly the TABLE 5 evaluation repeats (20 at EV ∈ {100, 500};
the 15 held-out repeats 6–20 at EV = 300); the three full-design rows must equal the
canonical `raw_runs.csv` aggregated under the same protocol exactly (proof that the ablation run replayed the
canonical scenario realizations); and every (EV, repeat) scenario of the two-prefix run must carry the
same `scenario_hash` as the committed ablation run (so the two extra Greedy-panel series are paired
with every other series). Coinciding curves in the Posterior panel
(the time-prior variant within the repeat confidence interval of the full
design; all-removed ~= without-carry-over) are drawn with
horizontally dodged markers (lines stay at the true x positions; only the markers are offset, as declared in the caption), with the overlapping variants rendered markers-only. The two two-prefix series in the Greedy panel coincide exactly (identical per-repeat accuracies) and are dodged the same way (±9 EV-session units); their data come from the committed run `ablation_two_prefix_run_20260908_170955_253026/`, and `scripts/build_table10_two_prefix.py` tabulates the same cells with paired differences (TABLE 9).
