# Manuscript Result Figure Generation

This document describes how to regenerate the final manuscript result figures.
Figures 1 and 2 are static manuscript assets and do not have public generation
scripts in this repository. Figures 3 through 6 each have one dedicated script.

The generation scripts preserve the committed data values, colors, markers,
line styles, legend labels, and font sizes. They use Times New Roman when it is
available; on systems without Times New Roman, Matplotlib falls back to
Liberation Serif, Nimbus Roman, or DejaVu Serif.

## Commands

Run these from the repository root:

```bash
export MPLCONFIGDIR=/tmp/mpl
python scripts/generate_paper_figure3_base_load_comparison.py --install-paper
python scripts/generate_paper_figure4_sampling_sensitivity.py --install-paper
python scripts/generate_paper_figure5_posterior_diagnostic.py --install-paper
python scripts/generate_paper_figure6_ablation_summary.py --install-paper
```

Each script writes first to a temporary output directory and copies the generated
PDF into `paper/` only when `--install-paper` is passed. Use `--output-dir` to
choose a different output directory and `--png` to also write a PNG preview.

## Figure 6 Ablation Data

Figure 6 uses `case_study/scalability_analysis/accuracy/figure6_ablation_simulated.csv`,
tabulated from the committed Section VI-C ablation reproduction run
`case_study/scalability_analysis/accuracy/ablation_run_20260711_164832_170489/`
(12 variant algorithms × EV ∈ {100, 300, 500} × 20 repeats on the canonical
base-load scenario seeds). The pipeline is:

```bash
# 1. (hours) re-simulate the 12 ablation variants on the canonical scenario seeds
python scripts/reproduce_all.py --mode ablation

# 2. (seconds) tabulate the plotting CSV from the committed ablation summary
python scripts/build_figure6_data.py

# 3. (seconds) render and install the figure
python scripts/generate_paper_figure6_ablation_summary.py --install-paper
```

`build_figure6_data.py` enforces two integrity gates before writing: every cell
must aggregate exactly the TABLE 5 evaluation repeats (20 at EV ∈ {100, 500};
the 15 held-out repeats 6–20 at EV = 300), and the three full-design rows must equal the
canonical `raw_runs.csv` aggregated under the same protocol exactly (proof that the ablation run replayed the
canonical scenario realizations). Coinciding curves in the Posterior panel
(the time-prior variant within the repeat confidence interval of the full
design; all-removed ~= without-carry-over) are drawn with
horizontally dodged markers (lines stay at the true x positions; only the markers are offset, as declared in the caption), with the overlapping variants rendered markers-only.
